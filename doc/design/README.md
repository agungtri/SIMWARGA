# 📐 Folder Desain Antarmuka & Mockup SIMWARGA

Folder ini memuat seluruh spesifikasi desain, fondasi sistem (*design tokens*), wireframe, dan mockup prototipe antarmuka sistem **SIMWARGA** berbasis **Material Design 3 (M3 / Material You)**.

---

## 📂 Berkas & Dokumen Terkait:

1. **[mockup-material-design.md](mockup-material-design.md)**
   * Panduan komprehensif token desain (*Color Roles, Typography, Elevation, Border Radius*).
   * Spesifikasi komponen M3 (Elevated Cards, Filter Chips, Split-Screen Verifier, Form Fields).
   * Wireframe skematis modul Dasbor RT/RW, Portal Bayar Warga (`bayar.html`), Validasi OCR, Matriks Blok 12 Bulan, dan Cetak Stiker QR.

2. **[mockup-preview.html](mockup-preview.html)**
   * Prototipe visual interaktif berbasis HTML mandiri (*standalone first / dual-mode*).
   * Dapat langsung dibuka di peramban web (*double-click / file:///*).
   * Memvisualisasikan 4 tampilan utama dengan fidelitas tinggi:
     1. Dasbor Eksekutif Desktop Pengurus RT/RW.
     2. Portal Konfirmasi Pembayaran Warga Mobile (Frame Ponsel).
     3. Layar Verifikasi Split-Screen & Evaluasi OCR Bendahara.
     4. Matriks Rekapitulasi Iuran 12 Bulan per Blok.
